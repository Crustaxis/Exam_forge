# Bancos de preguntas de la comunidad

Preguntas **originales** escritas por la comunidad, listas para importar en Tailor-test
(*Proyecto → Tema → Importar*). Es la forma más fácil de contribuir sin saber programar.

## Cómo añadir un banco

1. Escribe tus preguntas en el [formato JSON](../docs/FORMATO-PREGUNTAS.md). Puedes partir de
   [`ejemplo-razonamiento-numerico.json`](ejemplo-razonamiento-numerico.json).
2. Antes de enviarlo, **impórtalo en la app** para comprobar que no da errores.
3. Súbelo a esta carpeta desde el navegador (**Add file → Create new file**) con un nombre descriptivo en
   minúsculas y con guiones: `constitucion-titulo-preliminar.json`, `ingles-b2-gramatica.json`…
4. Añade una línea a la tabla de abajo en el mismo *pull request*.

Reglas:

- Solo preguntas **escritas por ti** (o generadas con IA y revisadas una a una por ti).
  Nada copiado de academias, libros ni exámenes con derechos.
- Comprueba que la respuesta marcada es la correcta y añade `explanation` siempre que puedas.
- Se publican con la licencia [MIT](../LICENSE) del proyecto.
