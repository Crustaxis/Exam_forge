# Tareas pequeñas pendientes

Lista de mejoras pequeñas, **una por pull request**. Se hacen en orden, de arriba abajo.
Las tareas grandes están en la [hoja de ruta](ROADMAP.md).

Cuando termines una, márcala con `[x]` y el número del PR **en el mismo PR**.

- [x] Tests de `src/lib/format.ts` (#2)
- [ ] Plantillas de *issue* (error / idea) en `.github/ISSUE_TEMPLATE/`
- [ ] Plantilla de pull request con checklist (`npm test`, `npm run build`) en `.github/pull_request_template.md`
- [ ] Insignia de CI y enlace a la demo publicada en el README
- [ ] `CODE_OF_CONDUCT.md` (Contributor Covenant, en español)
- [ ] `CHANGELOG.md` con lo incluido en la v0.1
- [ ] Etiquetas `aria-label` en los botones que solo tienen icono
- [ ] Pedir confirmación antes de borrar un proyecto o un tema (si aún no se hace)
- [ ] Al importar un JSON, indicar qué preguntas no son válidas y por qué (número de pregunta)
- [ ] Atajos de teclado en el examen: A–F para elegir opción, D para marcar dudosa
- [ ] Botón «Repetir solo las falladas» en la pantalla de resultados
- [ ] Ejemplo de JSON descargable en `docs/FORMATO-PREGUNTAS.md`
- [ ] Versión en inglés de `CONTRIBUTING.md` (`CONTRIBUTING.en.md`)
- [ ] Archivo `.editorconfig` para un formato uniforme
- [ ] Redactar *issues* «good first issue» a partir de la hoja de ruta (se entregan como texto para que el autor los publique)
