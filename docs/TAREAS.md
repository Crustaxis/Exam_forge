Lista de mejoras pequeñas, **una por pull request**. Se hacen en orden, de arriba abajo.
Las tareas grandes están en la [hoja de ruta](ROADMAP.md).

- [x] Tests de `src/lib/format.ts` (#2)
- [x] Plantillas de *issue* (error / idea / banco de preguntas) en `.github/ISSUE_TEMPLATE/` (#4)
- [x] Plantilla de pull request con checklist en `.github/pull_request_template.md` (#4)

- [x] `CODE_OF_CONDUCT.md` (#4)

- [ ] Botón «Repetir solo las falladas» en la pantalla de resultados

- [ ] Versión en inglés de `CONTRIBUTING.md` (`CONTRIBUTING.en.md`)
- [ ] Archivo `.editorconfig` para un formato uniforme
- [x] Publicar *issues* «good first issue» a partir de esta lista y de la hoja de ruta (#4)
